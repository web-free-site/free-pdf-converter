How to compress a PDF for WhatsApp

Chat apps often reject or slowly send large PDF attachments. Compressing the file first usually solves this. Free PDF Converter can shrink a PDF in your browser so the document never has to be uploaded to this site.

Steps

  1. Open the compress tool. Go to Free PDF Converter and choose the compress PDF tool.
  2. Add the file on your device. Select the PDF from your phone or computer. Processing stays in the browser tab.
  3. Compress and check the new size. Run compression and compare the output size with the original. If the file is still large, try a stronger setting if the tool offers one, or compress again after removing unneeded pages.
  4. Send the download. Download the compressed PDF and attach it in WhatsApp as a document. Open it once on your phone to confirm the pages are still readable.

Keep text readable

Heavy compression can blur scans and photos. If a page must stay sharp (a contract, a stamped form), compress less or compress only the image-heavy pages.

If the file is still too large

Split the PDF and send it in parts, or remove blank and duplicate pages first. A phone screenshot of a page is not a substitute for a document you need to print or sign.
