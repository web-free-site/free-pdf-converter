Frequently Asked Questions

What metadata exactly gets removed?

The document info fields (Title, Author, Subject, Keywords, Creator, Producer, and the creation and modification dates), the XMP metadata stream, the document ID pair in the trailer, and application-specific PieceInfo left behind by tools like Illustrator or InDesign. There are no options; it always clears all of these.

What stays in the file?

All visible content, plus form fields, annotations, bookmarks, links, and any file attachments. Names stored inside those elements, such as the author on a sticky-note comment, are not touched. To strip comments, scripts, and attachments as well, use Sanitize PDF.

Does it remove metadata from images inside the PDF?

No. Image data is left as it is, so any EXIF or XMP information a photo carried when it was placed into the PDF stays with that image. If that matters, Rasterize PDF re-renders every page as a fresh image, at the cost of selectable text.

How can I confirm the metadata is gone?

Open the cleaned file in View Metadata and check that the fields are blank. Running the same check on the original first shows you exactly what is about to be removed.

Can this be undone?

No. The cleaned file keeps no record of the removed values. Keep your original copy if you may need the author, dates, or other details later.

Will removing metadata reduce the file size?

A little, since the XMP block and info fields are dropped, usually only a few kilobytes. For a real reduction, follow up with Compress PDF.

Does it remove comments, annotations, or hidden text?

No, it only targets metadata. Comments and markup are annotations, which stay; Remove Annotations handles those. Hidden or white text remains part of the page content, so review the document itself if it went through several revisions.

Is my PDF uploaded while the metadata is removed?

No. The file is opened and rewritten by a PDF library in your browser, which is the point when the goal is anonymity: the document never touches a server, and no server log records what you cleaned.
